## 实际提示词示例

**zh / 原问法**

```text
猜中远。直接问“远”的前一个字是什么？只输出一个字即可。
```

**zh / 明确问紧挨 c 左边**

```text
只看开头的这个序列：猜中远。在这个序列中，紧挨着“远”左边的一个字是什么？只输出一个字即可。
```

**zh / 直接问第二项**

```text
序列：猜中远。这个序列的第二个字是什么？只输出一个字即可。
```

**en / 原问法**

```text
ice cream lake. What word comes immediately before "lake"? Output only one word.
```

**en / 明确问紧挨 c 左边**

```text
Read only this sequence: ice cream lake. In this sequence, which word is immediately to the left of "lake"? Output only one word.
```

**en / 直接问第二项**

```text
Sequence: ice cream lake. What is the second word in this sequence? Output only one word.
```

## 结果解读

两种改写下，随机组正确率均高于语义组。明确问“序列中紧挨 c 左边”时，两种语言的差距都比原问法更大，且语义组出现更多 A 类错误。中文随机组的正确率仍只有 52.8%，不能把这个版本称为已消除一般检索困难。
“直接问第二项”下的差异也保留，但表现与问左边不同：中文两组都较高，英文语义组仍明显落后。这说明差异的大小依赖问法。两种改写先在此前随机小样本诊断中固定，本次没有根据语义组输出再调整模板。
