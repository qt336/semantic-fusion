# Qwen3-8B：明确问左边，屏蔽前 16 层 B→A 注意力

生成进度：**4,000 / 4,000**；非简单或截断输出：59 条，已核对 59 条，待核对 0 条。

沿用上一轮固定的“在这个序列中，紧挨 c 左边”问法。中英文语义组和随机组各用原来的全部 500 条。未屏蔽与屏蔽两种条件在本轮成对重新生成，使用相同批次、同一模型和完全相同的输入。
屏蔽的是 **第 0–15 层、所有注意力头中，显示序列的 B 位置对 A 位置的注意力**：对应 softmax 前的 logit 设为负无穷，其余允许位置正常重新归一化。没有删除层或关闭整层注意力，也不屏蔽问题中重复出现的字词。
Qwen3-8B，BF16，关闭思考，贪心解码，最多 32 个输出 token。四个进程使用全部八张 GPU，在 screen qt1 中进行推理。

## 结果解读

在这一固定问法下，前 16 层屏蔽使中文语义正确率提高 62.6 个百分点、英文语义提高 61.2 个百分点，均超过对应随机组的增幅（27.6 和 2.8 个百分点）。中文语义组有 297 条、英文语义组有 315 条从 A 类错误变为正确 B。
英文语义组未屏蔽的 375 条 A 类错误中，318 条只回答 A，57 条回答 AB；屏蔽后的 69 条 A 类错误均只回答 A。因此，减少的不仅是完整 AB 输出，也包括仅输出首成分的错误。
这一变化方向与 toy model 中屏蔽早层 B→A 注意力后检索改善的现象一致。随机组也有所改善，说明干预的影响并不限于语义组合；语义组的首成分错误减少但尚未消失。

## 基线及核验记录

本轮重新生成的未屏蔽回答与上一轮相同问法的原始输出逐字一致：1998/2000。本轮批次仅包含这一种问法，上一轮批次混合三种问法；主表采用本轮成对基线，不混用上轮数值。
每个进程验证空屏蔽钩子与普通前向的 logits 完全相等，并在真实模型上检查第 0–15 层的目标注意力均为零。每个生成批次还核对各层实际修改的边数；元数据保存在 runtime_metadata 中。

全部精确提示词、聊天模板和 token IDs 保存在 items.jsonl；完整原始输出在 results/worker_*.jsonl；人工评分核对保存在 scoring_review.json。
