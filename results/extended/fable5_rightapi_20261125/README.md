# RightAPI 上 Fable 5 初版的零思考计数子集

基准共 3,000 个原始提示，每个语言与条件 500 题。单轮请求、无工具、输出上限 128 tokens。请求 claude-fable-5，使用 adaptive / low。只对回执明确计数为零、无思考块且模型标识一致的回答评分。空回答、拒答计入其他；首次提出的答案用于评分。

完成全部 3,000 题。1,273 条回执明确报告零思考 token 且无思考块，计入正确率和误答首项比例。1,295 条有思考证据，432 条无法确定。各条件独立筛选，题目集合可能不同。
