# RightAPI 上 Fable 5.2 的零思考计数子集

基准共 3,000 个原始提示，每个语言与条件 500 题。单轮请求、无工具、输出上限 128 tokens。请求 claude-fable-5-2，使用 adaptive / low。只对回执明确计数为零、无思考块且模型标识一致的回答评分。空回答、拒答计入其他；首次提出的答案用于评分。

完成全部 3,000 题。2,753 条回执明确报告零思考 token 且无思考块，计入正确率和误答首项比例。242 条有思考证据，5 条无法确定。各条件独立筛选，题目集合可能不同。

## 各条件可观察到思考的比例

有思考块、正计数或可见回答含推理标签，均归入有思考证据。明确零要求计数为零且无思考块。分母包括所有收到回执的题，未明确的单列。

首答核对示例：对 `common sense ship`，回复先单独给出带引号的 `common sense`，随后解释答案为 `sense`。沿用“开头直接回答整个 ab”规则，此例编码为 a。把带引号的词组解释为引语则会改变这一题的分类。

可见回答含推理标签的记录共 1 条，均从严格零思考子集中排除。其中“缝补高”的回执报告零且没有结构化思考块，但可见文本包含推理。

## 与 ZenMux 同题对照

另有 829 道原题曾在 ZenMux 用 Fable 5.2 的 adaptive / low 设置测过。逐题对齐后，RightAPI 有 762/829 条符合零计数条件，ZenMux 有 393/829 条。376 道题在 ZenMux 有思考证据、在 RightAPI 明确零计数，反方向为 10 道。每道题在每个通道各取一次回执，差异的来源尚未核实。
