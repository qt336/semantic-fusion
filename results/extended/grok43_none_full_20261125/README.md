# Grok 4.3 中英文前序检索测试

通过 ZenMux Responses API 指定 xAI 上游（`x-ai/grok-4.3:x-ai`），显式设置 `reasoning.effort=none`。使用固定 3,000 道原题，每组 500 题。已核对并复用其中 180 条先前的正式回答，另外完成 2,820 题。

## 加逗号前后的同题变化

| 语言 | 原先错答 a → 加逗号答对 b | 任意错 → 对 | 对 → 任意错 |
|---|---:|---:|---:|
| 中文 | 225 / 297 | 332 | 3 |
| 英文 | 323 / 467 | 323 | 3 |

每题发送独立的原始 user 提示词，输出上限 64 tokens。按首次实际提出的答案评分，直接回答整个 ab 计入 a。逗号组与语义组共用同一组三元组，随机组从原候选池独立抽取。Grok 专用分词器的三成分边界尚未独立核实。

3,000 次响应均报告模型 `x-ai/grok-4.3`、`effort=none`、0 个推理 token，均无 reasoning 输出项和非空历史响应 ID。接口报告的每题输入为 201–210 tokens，已完成响应的总费用为 0.36795250 美元。模型名和用量取自网关回执。

逐题文件中的 `fixed_180_subset` 标记最初的小测子集。两个阶段共用同一批 180 条回答。较早的 [其他通道连通性检查](../grok43_none_20261124/) 单独保存。
