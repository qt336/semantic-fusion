# Haiku 5.5 的前项检索结果（RightAPI）

请求与回执的模型标识均为 `claude-haiku-5-5`。每道题发起一次独立对话，只发送原始用户提示。思考设为 `adaptive`、等级 `low`、显示设为 `omitted`，输出上限 128 tokens。

已收到 3,000 条回执，1,098 条符合零计数筛选，1,442 条有思考记录，460 条无法判定。

仅对接口明确报告 0 个思考 token、无思考块或可见推理标签、模型标识一致且没有回退的回答评分。使用首次实际提出的答案，忽略开场语或复述。直接回答整个 ab 记作误答 a，空答和拒答记入其他。
