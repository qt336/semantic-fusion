# 卷积 + Softmax 注意力：算术与留出对子检索

更新时间：2026-11-14T05:55:00+08:00

原 hybrid 仅将第1、3层的 ELU+1 线性注意力改为因果 softmax；保留这两层的宽度3深度卷积。

- 10个 seed（101–110），仅使用 GPU 4、5，最多同时训练两个。
- 每轮27万条算术＋13.5万条检索；没有随机输出或高频共现附加任务。
- 检索训练留出01、02、21及普通对子9,10、15,20；单个符号仍参加训练。
- 各对子测试共用上下文，查询对子后紧随的符号，正确答案为对子第二项。
- 固定训练至第1200轮，每轮评估；下表是当前评估，最终均值只纳入全部完成的运行。
