# Hybrid seed104：反复spike与恢复后的性质

这份统计来自新重训的完整1200轮日志，核对模型恢复后的定性性质。

描述性分组：已有loss<0.5且算术正确率≥99%的状态后，遇到loss>1开始一段扰动；直到首次再次满足这两个条件才算恢复。期间再次出现的峰值归入同一段扰动。该分组只用于诊断，不用于更换论文的评估轮次。

共50段已恢复扰动，另有1199轮开始的末尾扰动在预算结束时尚未恢复。50个首次恢复点均满足：普通检索>语义检索；语义检索>原Transformer参考19.84%；首成分错误>0。进一步核对全程459个满足上述稳定条件的轮次，同样全部满足这三个关系。

| 指标 | 50个恢复点的范围 |
|---|---:|
| 算术正确率 | 99.01%–99.95% |
| 普通检索正确率 | 95.10%–97.40% |
| 语义检索正确率 | 55.70%–80.90% |
| 首成分错误率 | 14.04%–35.51% |

不能把这理解成每个峰值之后下一轮就恢复，或恢复后所有准确率数值完全不变。能支持的结论是：多次恢复后，同样的检索关系仍然出现，1175轮并非唯一观察到该性质的轮次。也不由这一条训练轨迹推论所有模型训练都容易发生spike。
